Questions

Everything you would ask first.

What is Ally?

Ally is a personal AI companion for Windows 10 and 11. It listens to a meeting, interview or call, suggests short answers to the questions it hears, keeps rolling notes and can answer from your own PDFs, spreadsheets and documents.

Can other people see Ally during screen sharing?

Ally's windows are excluded from screen sharing, recordings and screenshots using a Windows feature for protected content. It needs Windows 10 version 2004 or newer. Some remote-desktop tools behave differently, so test it before an important call.

Does Ally work offline?

Yes. In offline mode speech recognition (Whisper) and the AI (Ollama models) run on your own PC, with no account and nothing sent anywhere. The installer suggests models that fit your hardware and shows each download size before it starts.

Which AI services does Ally use?

Offline it uses local models. Online it uses Claude from Anthropic or ChatGPT from OpenAI with your own API key, which is encrypted on your PC. You pay that provider directly for what you use.

Is there help getting started?

Yes. After installing, Ally opens its Control Center with a short step-by-step guide in plain language. It checks that Ally can hear and answer, helps you pick a mode, fill it in with a preset, add your files and turn it on. You can skip it at any time, choose not to see it again, or open it again with the ? button.

Which file types can Ally use as reference material?

PDF, Excel, CSV, Word and plain text, up to 60 MB per file. Ally finds the passages relevant to each question and tells you which file they came from. Scanned PDFs without text cannot be read.

How big is the download?

The web installer is about 130 KB and downloads only what you choose. An offline setup is about 245 MB plus the models you pick, and an online setup starts from about 180 MB. A single all-in-one installer is also available on the releases page.

Why does Windows show a SmartScreen warning?

The installer is not code-signed yet, so Windows may show a notice the first time. Choose More info, then Run anyway.
